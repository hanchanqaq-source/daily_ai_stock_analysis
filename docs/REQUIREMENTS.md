## 不在 Work 1 范围

- 旧混合项目股票功能迁移

## 2026-07-29 R1 已确认需求

1. PP02 只含股票和 ETF，保持官方 v3.28.0 单用户模式。
2. 用户档案、用户切换、当前用户持久化、按用户隔离历史和用户级备份恢复不迁移。
3. 官方账户/组合事件账本是股票持仓唯一事实源。
4. 手动分析默认；本地定时、GitHub Actions 定时和自动推送默认关闭。
5. 周期报告只在应用内手动查看本周至今、邻近周、5周、10周、1个月和2个月。
6. Windows 第一发布形态为 NSIS 安装版并保留免安装 ZIP；便携自动更新后置。
7. 完整 DPAPI/safeStorage 在设置架构稳定后独立实现。
8. Windows 实机验收 Deferred；真实数据、Ready、合并和 Release 分别单独授权。

详细裁决见 `docs/pp02/R1_REQUIREMENTS_MIGRATION_CONFIRMATION.md`。
