# 错误与经验

本文件记录 PP02 开发过程中可复用的错误、根因、修复和验证方法。

## 2026-07-29｜Electron productName 变更必须同步 macOS 验收路径

- 现象：electron-builder 已成功生成新名称的 `.app` 和 DMG，但
  `scripts/build-desktop-macos.sh` 返回“expected one unpacked macOS app, found 0”。
- 根因：`package.json` 的 `productName` 已改为
  `PP02 AI Daily Stock Analysis`，验收脚本仍用旧固定路径
  `Daily Stock Analysis.app` 查找未打包应用及 DMG 内应用。
- 修复：同步两个 App 路径，并在 Desktop 单测中同时断言 PP02 名称存在、旧固定
  路径不存在。
- 验证：必须同时运行 Desktop Node 单测和 macOS unsigned Desktop package 门；
  单看 electron-builder 成功不足以证明验收脚本兼容新产品名。


## 2026-07-29｜产品级安全默认必须同步集成断言与设置帮助

- 现象：自动通知总开关实现后，完整后端门只剩 2 项失败：旧集成测试仍断言默认
  `notify=true`，新设置字段缺少 Web 帮助元数据。
- 根因：实现已改变产品级默认，但一个跨层测试和一个用户可见配置消费者未同步。
- 修复：将无显式开启的 API 集成断言改为 `notify=false`；为设置 Registry 补
  `help_key`，并补齐中英文标题、说明和帮助。
- 验证：安全默认改动必须同时覆盖真实入口行为、旧集成断言、配置 Registry、
  Web lint/build 和完整离线测试；仅让新增单元测试通过不足以收口。


## 2026-07-30｜新增前端测试门前必须先区分范围内失败和既有测试债

- 现象：R3.3 首次把 `npm test` 加入 `web-gate` 后出现 2 项失败：快捷持仓页面
  测试按预期失败；另一个 AlertRuleForm 测试要求日股/韩股选项，但现有告警组件
  只有中/港/美选项。
- 根因：原 `web-gate` 只执行 Lint 和 Build，97 个 Vitest 文件没有作为 PR
  阻断门；新增全量测试第一次暴露了与 R3.3 无关的历史契约不一致。
- 处理：R3.3 将正式新增门收敛为 PortfolioPage 专项测试，保证当前功能测试可阻断；
  告警日/韩市场不在本切片中修改，避免用无关补丁扩大产品范围。
- 验证：RED 时 PortfolioPage 为 1 fail / 28 pass；GREEN 为 29/29 pass；
  完整后端和 8 个 CI Job 同时通过。
- 经验：给既有大仓库启用此前从未运行的全量测试时，应先建立基线、标记历史失败，
  再决定独立治理切片；不能把历史失败误判为当前功能回归，也不能静默忽略。

## 2026-07-30｜目标持仓确认不得重复记录交易现金变化

- 现象：R3.3 计划写“交易/现金事件”，容易被误读为一次确认同时写交易和资金流水。
- 根因：官方组合重放已根据买卖交易自动增减现金；再写同额资金流水会造成双重扣款
  或双重入账。
- 处理：快捷持仓确认只追加一条官方交易事件，预览中的现金变化仅作展示；入金、
  出金仍使用独立资金流水。
- 验证：测试确认预览阶段交易数不变，确认后只增加一条交易，重放持仓达到目标数量。

## 2026-07-30｜异步 UI 测试必须等待状态提交而非只等待元素出现

- 现象：同一 R3.3 代码在实现 Run 中 Web 29/29 通过，Judge Head 重跑时既有
  “切换账户后丢弃迟到汇率结果”用例偶发读到“刷新中...”按钮尚未禁用。
- 根因：`findByRole` 只保证匹配文字的按钮已经出现，不保证 React 的
  `disabled` 状态已经在同一时刻提交；断言存在调度竞争。
- 修复：改用 `waitFor` 明确等待按钮进入禁用状态，业务实现和 R3.3 契约不变。
- 验证：修复 Head 必须重新运行 PortfolioPage 29 项测试及完整 8 门 CI；不得把
  单纯重跑成功当作修复证据。
