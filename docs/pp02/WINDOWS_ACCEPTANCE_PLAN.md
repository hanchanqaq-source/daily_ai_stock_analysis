# PP02 Windows 实机验收计划

云端验证通过不等于 Windows 本机通过。R0 只准备最小验收步骤；实际执行属于 R5，
需在用户 Windows 电脑上另行授权，且本 Work 不访问用户本机工作区。

## 前置条件

- 使用已验证的正式候选版本，不从旧工作树拼装。
- 先备份本机配置和数据库；首轮使用空库或测试库，不加载真实数据。
- 安装项目声明版本的 Python、Node/npm 与桌面运行依赖，不安装未声明的系统组件。
- 从 `.env.example` 建立本机测试配置；不在聊天、日志或截图中暴露密钥。

## 最小验收

| 步骤 | 操作 | 成功信号 | 失败证据 |
| --- | --- | --- | --- |
| 1 | 校验版本与候选 Commit | 版本、Commit 与正式候选一致 | 实际 SHA、安装来源 |
| 2 | 创建隔离环境并安装依赖 | 安装无未处理错误 | 完整错误和失败包 |
| 3 | 运行 `python scripts/check_ai_assets.py` 与离线 Python gate | 所有应执行检查通过 | 首个失败测试 |
| 4 | 运行 `tests/test_mimetypes_windows_init.py` | 不出现 Windows `mimetypes` 初始化卡死/异常 | 堆栈、Python/Windows 版本 |
| 5 | Web lint/build 与本机启动 | 构建成功，`/api/health` 和页面可打开 | 端口、控制台和服务日志 |
| 6 | Desktop 单元测试及打包/启动 | 测试通过，桌面窗口能启动并访问本地服务 | Electron/installer 日志 |
| 7 | 空库手动分析 | 用户手动触发可进入预期流程；定时未自动启动 | UI 状态和脱敏日志 |
| 8 | 默认开关 | 定时和自动推送均保持关闭 | 实际设置截图或配置键 |
| 9 | 关闭与重启 | 进程正常退出，重启后空库与设置一致 | 遗留进程、锁或数据损坏 |

## 明确不验收

- 真实用户数据库迁移、真实行情账户、通知发送、付费 LLM、自动交易和公网开放。
- 基金业务。
- Ready、合并、Release 或自动更新发布。
